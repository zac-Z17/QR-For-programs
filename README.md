# Vigilia Nacional PROCESOS 2026 · Revista digital

Página de bienvenida que se abre con el código QR de la vigilia (Jóvenes IDP Nicaragua, 10 de octubre de 2026).

- Se publica con GitHub Pages desde la rama `main` (carpeta raíz): https://zac-z17.github.io/QR-For-programs/
- `index.html` es la página completa; `a/` tiene las fuentes, el logo y la foto.
- El código fuente y el QR están también en el repo del proyecto (`pagina-qr/`).
